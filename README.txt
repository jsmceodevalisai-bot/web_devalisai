INSTRUCCIONES DE DESPLIEGUE:

Opción 1: Hosting estático (Netlify, Vercel, GitHub Pages)
1. Sube todos los archivos a la plataforma de hosting
2. Configura la página de inicio como index.html
3. ¡Listo!

Opción 2: Servidor web tradicional (Apache, Nginx, etc.)
1. Descomprime el archivo en el directorio de tu servidor web
2. Configura el servidor para servir los archivos HTML
3. ¡Listo!

Opción 3: Servidor local para pruebas
1. Descomprime el archivo
2. Abre index.html en tu navegador

NOTA:
